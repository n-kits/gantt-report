# Подложка OSM для карты топонимов — оценка (17.11.2026)

Решения пока нет, это заготовка на будущее. Связано с [issue #2](https://github.com/n-kits/gantt-report/issues/2)
(регионы полигоном и др.).

## Как сейчас

- `js/map/geo-map.js` (~570 строк): своя отрисовка на canvas, проекция Natural Earth, масштаб колесом
  и щипком, свои стили точек (`halves` и др.), пульсация сегодняшних точек, подсветка страны при
  наведении (`isPointInPath`), тёмная тема из CSS-переменных.
- Подложка — страны из `data/basemap.json` (168 КБ, `tools/build_basemap.py` из `cntpol10.geojson`,
  российская трактовка границ). Внешних серверов нет.
- Регионы: `data/admin1.json.gz` (1,6 МБ) пока использует только сборщик (`places.py`), на карту
  не выводятся.

## Требования, которые делают переход дорогим

1. **Границы — российская трактовка** (Крым и новые регионы — Россия). Стандартные плитки OSM
   рисуют границы по OSM; в растровой картинке их не убрать. Нужны векторные плитки без слоя
   границ + наши полигоны поверх.
2. **Подписи по-русски.** Растровые плитки OSM подписаны на местных языках («Донецьк», арабица).
   Русские — только векторный стиль с `name:ru`.
3. **Рабочая сеть** — там уже не резолвится `raw.githubusercontent.com` (issue #5). Сервер плиток
   нужно проверить до начала работ; карта станет зависеть от внешнего сервера.
4. **Условия плиток.** `tile.openstreetmap.org` — только малая нагрузка, обязательна подпись
   «© OpenStreetMap», без гарантий. Векторные без ключа — например, OpenFreeMap.
5. **Перенос своего.** Точки, пульсация, подсказки, подсветка стран — на API библиотеки
   (Leaflet или MapLibre GL). Таблица «Задачи и топонимы» и раздел `geo` в `live.json` не меняются.
6. **Тёмная тема.** Растровые плитки OSM только светлые; векторный стиль можно перекрасить.

## Меркатор

Плитки — всегда веб-Меркатор, выбора нет.
- Россия, Канада, Гренландия раздуты, выше ~85° обрезано. В масштабе Украина/Россия/Ближний Восток
  почти незаметно; мир целиком Natural Earth показывает честнее.
- Антимеридиан (Чукотка, Фиджи): полигоны рвутся — проверить заново.
- Полигоны перепроецировать не нужно — библиотека берёт lon/lat.

## Полигоны регионов

- 1,6 МБ gzip на canvas поверх Leaflet будет тормозить — нужно упрощение по масштабу или
  нарезка в плитки (`geojson-vt`).
- MapLibre рисует через WebGL и сам режет GeoJSON — объём посильный.
- Страны, регионы и «наши» границы в любом случае — наши слои поверх подложки без её границ.

## Варианты

| Вариант | Цена | Границы / подписи |
|---|---|---|
| A. Своя карта + подписи крупных городов и рек из Natural Earth | ~1 день | всё наше, по-русски, без внешних серверов |
| B. Leaflet + растровые плитки OSM, наши полигоны и точки поверх | 1–2 дня | границы OSM, подписи на местных языках; регионы тяжело |
| C. MapLibre GL + векторные плитки (OpenFreeMap), стиль `name:ru` без границ, наши страны/регионы/точки поверх | 3–5 дней | российская трактовка, по-русски, регионы без проблем; библиотека ~800 КБ |

**Рекомендация:** если подложка нужна для ориентира «где село относительно городов и дорог» при
сильном приближении — только C. Если хватит подписей крупных городов — A.
Перед C: за пару минут проверить доступность плиток OpenFreeMap из рабочей сети.

## Почему на странице разбора мест (`geo_manual.html`) подложка «просто работает»

Там вариант B (Leaflet с cdnjs + плитки OSM, ~20 строк), и ни один камень не мешает: смотрит только
пользователь локально на ПК со сборщиком; границы и местные подписи там даже полезны для сверки с
OSM/Яндексом; поверх 2–10 маркеров; нет тёмной темы и своих стилей точек.
Быстрая проверка, как выглядят границы OSM: открыть страницу разбора и приблизить Крым и Донбасс.
