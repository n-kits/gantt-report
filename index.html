Легенда: цвет полосы = статус/срок. завершена в срок завершена с нарушением срока на рассмотрении на рассмотрении, срок нарушен выполняется выполняется, срок прошёл. Обводка у полос «на рассмотрении» — цвет, которым полоса станет после завершения. ◆ — интервал крайнего срока. Нижняя строка — пересечение задач.

Карта топонимов

серый круг — все задачи с этим топонимом за три дня, оранжевое ядро — из них сегодня (с 04:00); без ядра — только вчера и позавчера. сегодня (с 04:00) вчера и позавчера. Размер точки — число задач с этим топонимом. Размер — все задачи за три дня; доли по дням: сегодня вчера позавчера. Пунктирный ободок — координаты приблизительные. страна сегодня страна раньше. Колесо мыши — масштаб, перетаскивание — сдвиг.
