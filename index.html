Лента Аналитика

Легенда: цвет полосы = статус/срок. завершена в срок завершена с нарушением срока на рассмотрении на рассмотрении, срок нарушен выполняется выполняется, срок прошёл зарегистрирована не обработана. Обводка у полос «на рассмотрении» — цвет, которым полоса станет после завершения. ◆ — интервал крайнего срока. Нижняя строка — пересечение задач.

Карта топонимов

серый круг — все задачи с этим топонимом за три дня, зелёное ядро — из них сегодня (с 04:00); без ядра — только вчера и позавчера. сегодня (с 04:00) вчера и позавчера. Размер точки — число задач с этим топонимом. левая половина — задачи сегодня (с 04:00), правая — вчера–позавчера; размер каждой — по своему числу задач. Место только в один из дней — целый круг. сегодня (с 04:00) и вчера–позавчера — отдельно, размер каждого — по своему числу задач. Подсказка «Москва 9 / 23» — задач сегодня / вчера–позавчера. Размер — все задачи за три дня; доли по дням: сегодня вчера позавчера. Пунктирный ободок — координаты приблизительные. страна сегодня страна раньше. Колесо мыши — масштаб, перетаскивание — сдвиг.

Источник координат: кэш Nominatim полигон страны оценка модели (не подтверждено геокодером). «км» — насколько найденная точка отстоит от оценки модели; красным — больше 50 км.
